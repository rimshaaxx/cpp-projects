#  Terminal Ouija Board

A tiny terminal-based Ouija board made in C++.

Made using:
- 2D grid system with `vector`
- `map` to store board locations
- ANSI escape codes to hide, move, and show the cursor
- `rand()` and `time()` for random ghost responses

...and yehh that's pretty much it. 😭

## 🛠️ How to Run

Compile and run using `g++`:

```bash
g++ main.cpp -o ouija
./ouija
```
